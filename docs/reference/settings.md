# Settings reference

Source: [settings.js](../../src/core/settings.js). Keys persist under `tomm.settings`; [usage](../user-guide.md#settings-and-persistence) explains live/reset behaviour.

| Key | Default | Range | Meaning |
| --- | --- | --- | --- |
| `residentsPerTilePerFloor` | `3` | 1–8, integer | Residential capacity per footprint cell per floor |
| `maxPopulation` | `1000` | 30–1,000, integer | Admission cap; reducing it does not evict residents |
| `glowIntensity` | `1` | 0.2–2, increments of 0.1 | Night emissive strength |
| `shadows` | `false` | boolean | Real-time renderer shadows |
| `councilTemperature` | `0.15` | 0–1, normalized to 0.01; UI steps 0.05 | LLM sampling temperature |
| `councilSittingsPerDay` | `2` | 1–12, integer | Scheduled decision windows per game day |
| `cabinetMotionsPerSitting` | `5` | 1–5, integer in Settings | Mayor approval cap; all five ministers still receive a call |
| `averageCongestionThreshold` | `0.5` | 0.1–0.9, increments of 0.05 | Average between-sitting road-planning gate |
| `autoCouncil` | `true` | boolean | Scheduled LLM decisions |
| `fitTown` | `true` | boolean | Auto-fit acquired land at changes and three-game-hour boundaries |
| `defaultSpeed` | `100` | 0, 1, 2, 4, 10, 20, 50, 100 | Start/reset clock multiplier; 0 pauses |
| `cameraYaw` | `34.5` | −180–180°, increments of 0.5 | Stored azimuth |
| `cameraPitch` | `64` | 0–80°, integer | Stored polar tilt; 0° is overhead |
| `cameraZoom` | `228` | 40–500 m, integer | Stored camera distance |
| `cameraTargetX` | `-20` | −96–96 m, increments of 0.5 | Stored pan X |
